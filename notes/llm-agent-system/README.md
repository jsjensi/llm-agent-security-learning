# LLM Agent 系统学习文档

本目录用于存放对 LLM Agent 系统的系统化讲解，与每日学习日志分开维护。

## 文档分类

### 1. 基础讲解

记录核心概念及其区别，例如：

- LLM 与 LLM Agent；
- Prompt、上下文与上下文学习；
- 短期记忆（STM）与长期记忆（LTM）；
- Embedding、相似度检索与 RAG；
- 工具调用与任务规划。

### 2. 系统框架

记录 Agent 的组成模块和完整工作流程，例如：

`用户查询 → 任务规划 → 记忆检索 → LLM 推理 → 工具调用 → 结果观察 → 回答或继续行动 → 记忆写回`

### 3. 应用案例

使用具体案例理解 Agent 系统，并记录任务目标、工具、记忆使用方式和安全风险。

## 记录原则

- 区分“模型能力”和“Agent 系统能力”。
- 先解释模块作用，再介绍具体实现。
- 每个抽象概念至少配一个简单案例。
- 区分论文事实、自己的理解和尚未验证的推测。
