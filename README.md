# 大语言模型智能体安全

本目录用于整理大语言模型智能体安全相关论文，以及阅读、复现过程中积累的知识和实验资料。

## 目录说明

- `papers/`：论文原文和中文翻译。
- `plans/daily/`：唯一的七天每日学习安排。
- `journal/`：每天的学习内容、提问和理解修正。
- `notes/`：当前学习所需的精简笔记。
- `reference/minja-toy/`：此前生成的完整 toy 参考答案，第 6 天后再查看。

1. 打开 `plans/daily/README.md`，只完成当天任务。
