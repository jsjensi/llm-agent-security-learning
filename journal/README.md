# 每日学习日志

本文件夹记录每天的学习内容、自己提出的问题，以及当时的理解。

## 使用方式

1. 每天新建或继续当天文件，命名格式：`YYYY-MM-DD-dayN.md`
2. 先写“今天学了什么”，再写“我的提问”
3. 回答先自己写，再与导师讲解对照，在“修正后的理解”中补充
