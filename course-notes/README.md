# 视频课程学习文档

本文件夹用于记录与 MINJA 学习相关的视频课程笔记。

## 当前课程范围

- `20`：大模型基础、微调与部署
- `21`：RAG 检索增强与开发框架
- `22`：智能体架构与多 Agent 协作

当前只学习与 MINJA 直接相关的内容：

1. GPT、提示词和上下文学习。
2. RAG、向量表示、相似度和 Top-k 检索。
3. Agent 的规划、工具、短期记忆和长期记忆。

微调、量化、部署、多 Agent 框架等内容暂时不展开。

## 文件命名

每节视频单独记录，建议格式：

`课程编号-章节编号-主题.md`

例如：

- `20-01-GPT系列算法概述.md`
- `21-02-RAG整体流程.md`
- `22-04-Agent记忆信息.md`

可以复制 `TEMPLATE.md` 开始记录。

## 记录原则

- 先用自己的话总结，再补充标准术语。
- 只记录与当前论文有关的知识，不逐字抄写字幕。
- 必须写下不理解的问题。
- 不在文档中保存视频密钥、私人下载链接或账号信息。
