# 零基础学习路线

## 总体顺序

Agent 基础 → RAG 与记忆机制 → 智能体安全基础 → MINJA 具体案例 → 自进化 Agent 安全框架 → MINJA 代码复现。

## 论文优先级

### 第一阶段：Dong 等——MINJA

论文：*Memory Injection Attacks on LLM Agents via Query-Only Interaction*

这篇论文场景具体，适合作为第一篇精读论文。学习重点：

1. Agent 的短期记忆与长期记忆。
2. 基于 Embedding 的相似度检索。
3. 攻击者能力、目标和限制条件。
4. Bridging Steps（桥接步骤）。
5. Progressive Shortening Strategy（渐进缩短策略）。
6. 注入成功率、攻击成功率和正常任务性能等指标。

建议先阅读摘要、图 1、引言和威胁模型，再学习方法与实验。零基础阶段不必立即完整复现。

### 第二阶段：Lin et al.——自进化 Agent 安全

论文：*Safety in Self-Evolving LLM Agent Systems: Threats, Amplification, and Case Studies*

这篇论文范围更广，适合在理解具体记忆攻击后建立完整知识框架。学习重点：

1. 自进化 Agent 的定义与基本条件。
2. MLAS 矩阵：五类功能模块与五个生命周期阶段。
3. 攻击如何从单次影响转化为长期持久化影响。
4. 跨代积累、选择性放大和能力棘轮等放大效应。
5. 静态防御在自修改系统中的局限性。

第一次只需阅读摘要、引言、第 2 节和结论；完成 MINJA 学习后再回看完整威胁框架。

## 前置知识

开始精读论文前，先掌握以下内容：

- LLM、Token、Prompt 和上下文窗口。
- In-Context Learning（上下文学习）。
- Agent 的规划、工具调用和执行流程。
- 短期记忆、长期记忆与共享记忆。
- Embedding、向量数据库、相似度检索和 RAG。
- 提示注入、间接提示注入、数据投毒和后门攻击。
- 威胁模型中的攻击目标、攻击者能力与安全假设。
- ASR、准确率、效用下降等常见实验指标。

## 分阶段学习计划

### 阶段 0：基础准备

目标：能够解释一个带长期记忆的 Agent 如何接收查询、检索记录并生成结果。

产出：

- 在 `notes/` 中整理 Agent、RAG、Embedding 和长期记忆的概念笔记。
- 在 `questions/` 中记录无法理解的术语和机制。

### 阶段 1：MINJA 初读

目标：不看公式也能讲清楚攻击流程。

产出：

- 一页论文摘要。
- 一张“查询 → 恶意记忆写入 → 相似记录检索 → 受害查询被影响”的流程图。
- 威胁模型和攻击假设清单。

### 阶段 2：MINJA 精读

目标：理解桥接步骤、渐进缩短策略和实验设计。

产出：

- 方法章节笔记。
- 实验变量与评价指标表。
- 对论文假设、局限性和可能防御方法的总结。

### 阶段 3：Lin 框架学习

目标：能使用 MLAS 矩阵分析一个 Agent 系统的攻击面。

产出：

- MLAS 五类模块与五个生命周期阶段的概念笔记。
- 将 MINJA 定位到 Cognitive Resource（认知资源）相关攻击面。
- 总结自进化导致攻击持久化和放大的原因。

### 阶段 4：代码复现

目标：先复现最小攻击链路，再尝试论文完整实验。

建议顺序：

1. 实现简单的向量记忆库。
2. 实现查询、记忆写入与 Top-k 检索。
3. 构造无攻击的基线实验。
4. 加入受控的恶意记忆样本。
5. 观察检索结果和 Agent 输出变化。
6. 在隔离环境中尝试 MINJA 的渐进缩短过程。
7. 记录参数、随机种子、模型版本和结果。

代码放入 `code/`，输入数据和实验结果放入 `data/`，流程图和截图放入 `assets/`。

## 学习原则

- 先理解攻击机制，再追求完整复现。
- 区分论文事实、自己的推断和尚未验证的问题。
- 所有攻击实验仅在本地、隔离且获得授权的环境中进行。
- 每次实验保留配置和结果，确保能够重复运行。
